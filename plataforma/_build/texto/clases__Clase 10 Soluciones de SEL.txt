Soluciones de sistemas y variables libres
En el ejemplo anterior, quedó una variable libre .
Variables básicas y variables libres
Variables básicas: Variables cuyas columnas son pivote.
Variable libre: Variable cuya columna no es pivote. Funcionan como
parámetros, su valor puede elegirse arbitrariamente, y determina todas las
demás variables.

Soluciones de sistemas y variables libres
Criterio de consistencia
Un sistema lineal es consistente si y solo si una forma escalonada de la
matriz aumentada NO contiene una fila del tipo
[ 0 · · · 0 | b ] , b ̸= 0.
Número de soluciones
Si el sistema es consistente, entonces tiene:
única solución si no hay variables libres,
infinitas soluciones si hay al menos una variable libre.
