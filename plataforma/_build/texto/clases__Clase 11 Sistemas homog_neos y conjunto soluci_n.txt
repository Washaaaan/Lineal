Sistemas lineales homogéneos
Un sistema es homogéneo si puede escribirse como

El sistema homogéneo siempre tiene al menos una solución, a saber

Conjuntos solución de sistemas lineales
Existencia de soluciones no triviales
El sistema homogéneo Ax = 0 tiene una solución no trivial si y solo si el
sistema tiene al menos una variable libre.
Más aún, las soluciones de los sistema homogéneo siempre son conjuntos
generados:
x = t1u1 + t2u2 + . . . + tkuk
Esta forma describe rectas, planos, etc. que pasan por el origen.

Sistemas no homogéneos
Para un sistema
Ax = b
con al menos una solución p, el conjunto solución completo tiene la forma:
x = p + vh,
donde vh recorre todas las soluciones del sistema homogéneo Ax = 0.
