4. Demuestre las siguientes afirmaciones:
a) Si el conjunto {u, v, w} de vectores en Rn es linealmente independiente, entonces el con-
junto {u − v, u + v, w} tambi´ en es linealmente independiente.
Soluci´ on:
Si α(u − v) +β(u + v) +γw = 0, tenemos que ( α + β)u + (β − α)v + γw = 0, como u, v, w
es l.i. tendremos que α + β = 0, β− α = 0, γ= 0 y por lo tanto
α = β = γ = 0
por lo tanto el conjunto {u − v, u + v, w} es linealmente independiente.
b) Si A y B son matrices de n × n tales que ABT es invertible entonces B es invertible.
Soluci´ on:
Como ABT es invertible, existe C tal que C(ABT ) = Id, entonces (CA)BT = Id, es decir
CA es la inversa de BT , entonces BT es invertible, luego B tambi´ en lo es.
c) Si A es una matriz de n × n y las columnas de A2 generan Rn entonces las columnas de
A son linealmente independientes.
Soluci´ on:
Si las columnas de A2 generan Rn tenemos que A es invertible y por lo tanto |A2| ̸= 0,
como |A2| = |A|2 tenemos que |A| ̸= 0 y por lo tanto A es invertible y de este forma las
columnas son l.i.
