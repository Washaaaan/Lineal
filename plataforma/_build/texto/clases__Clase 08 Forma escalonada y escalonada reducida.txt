[

Dadas dos filas Fi y Fj de una matriz, las operaciones elementales
permitidas son:
(1) Intercambio de filas: Fi←→ Fj
(2) Multiplicar una fila por un escalar no nulo:
Fi−→ c Fi, c̸= 0
(3) Sumar a una fila un múltiplo de otra fila: Fi−→ Fi + c Fj
Estas operaciones corresponden a reemplazar una ecuación del
sistema por una ecuación equivalente. No alteran el conjunto solución
del SEL.
¿Cómo usamos estas operaciones? ¿Hasta donde llegar?

Operaciones por fila y formas escalonadas
Inversas de las operaciones de filas
Cada una de las operaciones de filas son reversibles. En efecto,
La inversa del intercambio Fi←→ Fj es el mismo intercambio.
La inversa de la multiplicación Fi−→ c Fi es Fi−→ 1c Fi.
La inversa del reemplazo Fi−→ Fi + c Fj es Fi−→ Fi− c Fj
Ejemplo: Realice una operación de filas de cada tipo a la matriz

0 3 −6 6 4 −5
3 −7 8 −5 8 9
3 −9 12 −9 6 15

Formas escalonadas
Comentarios
Si una matriz A se puede transformar a una matriz B con operaciones
de filas, decimos que A y B son equivalentes por filas .
En el caso de SEL, si dos matrices ampliadas son equivalentes por
fila, entonces tienen el mismo conjunto solución.
El recíproco es falso: Pueden existir ecuaciones extra o no existir
solución.
Ejemplo: Considere las matrices ampliadas

0 0 4 −2

Formas escalonadas
¿Cómo sabemos hasta donde hacer operaciones de fila? Llamaremos
entrada principal a la primera entrada no 0 de una fila.
Matriz escalonada (forma escalonada por filas)
Una matriz está en forma escalonada si cumple:
1) Todas las filas no nulas están arriba de las filas nulas.
2) La entrada principal de cada fila aparece a la derecha de la entrada
principal de la fila superior.
3) Todas las entradas debajo de cada entrada principal son ceros.


⋆ ∗ ∗ ∗
0 0 ⋆ ∗
0 0 0 0


Toda matriz es equivalente a matrices escalonadas.

Una matriz está en forma escalonada reducida si, además:
4) Cada entrada principal es 1.
